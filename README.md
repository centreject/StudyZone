# StudyZone (스터디존)

2025년 2학기 **소프트웨어공학** 팀 프로젝트 포트폴리오입니다.
교내 자습 공간(인커라, 도서관, 스타트업 라운지 등)의 좌석을 실시간으로 조회·예약하고,
신고·패널티·친구 기능을 제공하는 **좌석 예약 플랫폼 "스터디존"**의 기획부터 홍보 영상과 최종 발표까지의 산출물을 주차 순서대로 정리했습니다.

> `git log --reverse`로 실제 작업 순서대로 진행 과정을 따라갈 수 있습니다.

## 정리 기준

- **날짜**: 커밋 날짜는 각 파일 내부 메타데이터(docx/xlsx의 작성·수정 시각, PDF 생성일, 캡처 파일명의 시각)를 기준으로 했습니다.
  내부 시각 정보가 없는 파일은 앞뒤 산출물을 기준으로 날짜를 추정했으며, 해당 커밋 메시지에 `(날짜 추정)`이라고 적어 두었습니다.
- **중복 제거**: 내용이 완전히 같은 사본(예: `소웨공 제출과제/` 폴더, `(1)` 사본)과 `.DS_Store`는 하나만 남겼습니다.
  이전 구조 그대로의 전체 파일은 `master` 브랜치의 최초 커밋에 남아 있습니다.
- **같은 이름, 다른 내용**: `예약관리 및 이용내역 목업(녹화용).html`은 두 버전이 있어 `_수정본`을 붙여 둘 다 보관했고,
  `StudyZone Pitch Deck (Revised).pdf`도 두 버전이 달라 이전 버전에 `_초안`을 붙였습니다.
