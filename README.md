# StudyZone (스터디존)

2025년 2학기 **소프트웨어공학** 팀 프로젝트 포트폴리오입니다.
교내 자습 공간(인커라, 도서관, 스타트업 라운지 등)의 좌석을 실시간으로 조회·예약하고,
신고·패널티·친구 기능을 제공하는 **좌석 예약 플랫폼 "스터디존"**의 기획부터 홍보 영상과 최종 발표까지의 산출물을 주차 순서대로 정리했습니다.

> `git log --reverse`로 실제 작업 순서대로 진행 과정을 따라갈 수 있습니다.
> 각 커밋 메시지에는 날짜를 정한 근거가 적혀 있습니다.

## 정리 기준

- **날짜**: 파일 내부 메타데이터(문서 속성, PDF 생성일, 이미지 XMP), 캡처 속 디스코드 메시지 시각, 파일명의 시각, 화면 속 날짜 표기를 근거로 했습니다.
  근거가 간접적인 커밋 9개에는 커밋 메시지에 `(날짜 추정)`과 추정 이유를 적었습니다.
- **중복 제거**: 내용이 바이트 단위까지 같은 사본과 `.DS_Store`는 하나만 남겼습니다.
  이전 구조 그대로의 전체 파일은 `master` 브랜치의 최초 커밋(`cfa0604`)에 남아 있습니다.
- 자세한 분석 과정과 근거는 [`docs/저장소_정리_작업기록.md`](docs/저장소_정리_작업기록.md)에 있습니다.
